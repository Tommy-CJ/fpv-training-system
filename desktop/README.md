# Windows 托盘采集程序

这个程序在 Electron 主进程直接占用用户选定的接收阵列 COM 串口，并连接云端 `/live-ws`。它有独立的实时监控窗口；关闭窗口后托盘采集继续运行。关闭或最小化 Edge 不会关闭采集进程。现有教练/观众页面继续负责事件管理和展示，服务器 SQLite 仍是历史权威。

## 开发与打包

在 `desktop` 目录运行：

```powershell
npm install
npm run verify
npm start
npm run package:win
```

如果 Electron 官方下载很慢，可先运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/download-electron.ps1`；脚本会按官方 SHA-256 校验镜像文件，打包器随后使用这份本地 ZIP。

默认打包输出为 `out/manual-connect/FPV-Training-Collector-win32-x64/FPV-Training-Collector.exe`。本次验证包位于本机 `out/rebuild-grace-20261121`；这些输出目录不提交到 Git。请把整个程序目录放在固定位置，不能只复制 EXE，也不要在启用登录启动后移动目录。首次启动会显示实时监控窗口，**必须手动选择接收阵列串口并点击“连接”**；即使只有一个 STM32 串口也不会自动连接，因为飞控可能使用相同的 VID/PID。重启程序或 Windows 登录启动后也须手动点击连接；已手动连接后，程序只会自动重连身份一致的串口，同一 COM 号若被其他设备占用则要求重新选择。列表显示 Windows 设备名称、COM 号和可用的设备序列号。它默认随 Windows 登录静默启动，可在托盘菜单关闭。日志、配置和可靠缓存保存在 Electron 的用户数据目录；托盘菜单可打开该目录。

单击托盘图标或点击“打开实时监控”可重新显示窗口；亮色窗口持续更新帧率、上传、ACK、缓存和各接收机原始通道值。当前训练事件的接收机卡片显示对应飞手姓名，每张卡片单独提供“对频”按钮。点击“打开教练网页”会打开带 `?nativeCollector=1` 的云端网页。这个参数会让教练网页停止自动占用 Web Serial，网页通过云端实时广播显示托盘收到的当前帧。要回到浏览器直接采集模式，可用 `?nativeCollector=0` 打开教练网页并退出托盘程序。

## 数据语义

- 每个完整串口 JSON 帧至多发一条当前 `liveOnly` 实时消息。Socket 背压时丢弃当前展示帧，不阻塞串口读取。
- 约每 200 毫秒从原始接收机数据选一条可靠快照，**先写本机 SQLite**，再发 `durable + persistOnly + packetId`。仅服务器处理成功的 ACK 才删除本机记录。
- 断网旧包用原采集时间与明确的 `backfill: true` 补传。当前实时帧优先；补传不广播旧摇杆。
- 在线可靠帧最多允许 3 个未确认包进入同一连接。若最早的在线 ACK 超过 3 秒仍未收到，托盘放弃旧连接并重连；未确认包保留在 SQLite，按原采集时间显式回补。这防止网络假在线时大量旧包恢复后被云端按同一到达时刻落库。
- 成功发出回补完成通知后，托盘给服务器最多 12 秒完成历史重建；这期间不把已发可靠包因 3 秒 ACK 延迟重复发送或误判断线。宽限期后无 ACK 仍重连。服务器全量重建本身可能暂停实时处理数秒，这项宽限不消除服务器暂停。
- 托盘退出或机器重启后，SQLite 未确认记录继续保留；重启连接后重放。所有接收机的历史仍由云端 SQLite、当前事件和历史归属计算。
- 云端明确返回 `orphaned` 的可靠包会在本机 SQLite 中标记为“拒收保留”，停止自动重发，重启后也不会重发；原始包和拒收原因仍保留供排查。普通未确认包继续重试，只有成功 ACK 才删除原始包。

程序无法跨越系统睡眠、关机、USB 拔出或被人为结束的进程继续读取。正式长时训练前，需在实机验证 COM 识别、事件切换、20 小时最小化、断网回补、观众刷新和 Windows 电源设置。切换前先退出浏览器采集或关闭它的串口，避免 COM 口竞争。云端服务与网页需要一起部署本次的 `native_collector` 透传改动，教练页才会显示托盘源。
